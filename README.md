# Blender Portfolio

Blenderを使用した3DCG制作のポートフォリオです。

## 01. キャラクター制作

参考書に沿って、キャラクターのモデリングをゼロから行い、アニメーション・レンダリングまでの全工程を自ら制作しました。

### 使用ソフト
- Blender

### 制作内容
- キャラクターモデリング
- 衣装・装飾品のモデリング
- UV展開
- マテリアル設定
- テクスチャペイント
- リギング（骨格の設定）
- ウェイトペイント
- シェイプキー（表情の設定）
- アニメーション制作
- カメラ・ライティング設定
- コンポジット
- トゥーンレンダリング
